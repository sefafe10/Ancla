# Instrucciones del proyecto

- Al terminar cada cambio solicitado por el usuario, revisa el diff, compila o verifica lo necesario y crea un commit con un mensaje breve y natural en español.
- Usa la identidad Git ya configurada en este equipo. No inventes ni alteres el nombre o correo del autor.
- Mantén fuera del repositorio `local.properties`, carpetas de compilación y archivos de diagnóstico locales.
- Si el remoto de GitHub está configurado y hay acceso, publica los commits en `origin/main`; si no, conserva el commit local e informa claramente del bloqueo de acceso.
